### 1. Shiv AI Video Assistant

An AI-powered video intelligence application for turning long-form video and meeting content into useful, structured information such as transcripts, summaries, action items, key decisions, open questions, and conversational Q&A.

**Technology:** Python · Streamlit · OpenAI Whisper · Sarvam AI · Mistral AI · LangChain · ChromaDB · Sentence Transformers · yt-dlp · FFmpeg

### 2. Shiv RAG AI — Intelligent Book Assistant

A document question-answering system that transforms uploaded PDFs into a searchable semantic knowledge base and generates context-aware answers using retrieval-augmented generation.

**Technology:** Python · Streamlit · LangChain · PyPDFLoader · HuggingFace · Sentence Transformers · ChromaDB · Mistral AI

### 3. Shiv AI Multi-Agent Research System

A structured agentic research workflow that separates research into specialized stages including web search, source reading, report generation, and final critique.

**Technology:** Python · LangChain · Mistral AI · Tavily · BeautifulSoup · Streamlit · Prompt Engineering

### 5. Super Store Sales Analysis

An interactive business-intelligence project focused on sales, profitability, customers, products, regional performance, trends, and forecasting.

### 7. Shiv Heart Disease Prediction Model

## 💻 Run Locally

### Prerequisites

- Python 3.x
- Git
- pip or uv

### 1. Clone the repository

```bash
git clone https://github.com/sandilyashivshankar/Personal-Portfolio.git
cd Personal-Portfolio
```

### 2. Install dependencies

Using pip:

```bash
cd portfolio
pip install -r requirements.txt
```

Or using uv:

```bash
cd portfolio
uv pip install -r requirements.txt
```

### 3. Run the application

```bash
streamlit run app.py
```

Or:

```bash
uv run streamlit run app.py
```

Then open:

```text
http://localhost:8501
```

## 🔐 Security

Secrets and credentials should never be committed to the repository.

Do not commit:

```text

API keys
Streamlit secrets
authentication tokens
GitHub tokens
private credentials
```

Use environment variables during local development and **Streamlit Secrets** for deployed applications.
