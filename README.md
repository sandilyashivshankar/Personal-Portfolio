## Local Development

### Prerequisites

- Python 3.x
- pip or uv
- Git

### Clone the repository

```bash
git clone https://github.com/sandilyashivshankar/Personal-Portfolio.git
cd Personal-Portfolio
```

### Install dependencies

Using pip:

```bash
cd portfolio
pip install -r requirements.txt
```

Or using uv:

```bash
cd portfolio
uv pip install -r requirements.txt
```

### Run the portfolio

```bash
streamlit run app.py
```

Or:

```bash
uv run streamlit run app.py
```

Open:

```text
http://localhost:8501
```

## Security

Never commit secrets or credentials to GitHub.

Do not commit:

```text
.env
Streamlit secrets
API keys
authentication tokens
GitHub tokens
private credentials
```

Use environment variables for local development and **Streamlit Secrets** for deployed applications.
